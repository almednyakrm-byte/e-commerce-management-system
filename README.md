# نظام إدارة المتجر الإلكتروني (إدارة المنتجات، إدارة المخزون، شحن)
==========================

## ملخص المشروع

نظام إدارة المتجر الإلكتروني هو تطبيق إلكتروني يهدف إلى إدارة المتجر الإلكتروني بكل سهولة. يتيح للمستخدمين إدارة المنتجات، وإدارة المخزون، وشحن المنتجات بسهولة.

### الغرض من المشروع

* إدارة المنتجات: إضافة، تعديل، حذف المنتجات.
* إدارة المخزون: إضافة، تعديل، حذف المخزون.
* شحن المنتجات: إضافة، تعديل، حذف الشحن.

## بنية المشروع

### البنية التحتية

* لغة البرمجة: Python 3.9
* إطار عمل: Flask
* قاعدة البيانات: PostgreSQL
* نظام إدارة قواعد البيانات: SQLAlchemy

### البنية التحتية باستخدام Docker

* Dockerfile: يحتوي على تكوين Docker لتشغيل التطبيق.
* docker-compose.yml: يحتوي على تكوين Docker Compose لتشغيل التطبيق مع قاعدة البيانات.

## تشغيل المشروع باستخدام Docker Compose

### الخطوات

1. تأكد من أن Docker و Docker Compose مثبتين على جهازك.
2. افتح المجلد المشروع في شاشة الأوامر.
3. استخدم الأمر التالي لتشغيل المشروع:
bash
docker-compose up

4. افتح متصفحك واكتب `http://localhost:5000` في شريط العنوان.
5. سوف تظهر لك صفحة تسجيل الدخول. أدخل بيانات تسجيل الدخول الخاصة بك.
